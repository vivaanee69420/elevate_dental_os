# Data Room dictionary

Generated by `npm run data-room:dictionary` (backend). Do not edit by hand.

All money is integer pence. Timestamps are UTC instants (the UI shows London time). "PII" columns are withheld from every role except an owner who explicitly requests them. "Derived" columns are computed from the row by the rules noted in each description.

## How the numbers are defined

- **Patient appointment**: a Dentally appointment with a patient attached (`pms_patient_id` not null). Diary blocks (lunch, admin) are excluded, matching Dentally's "With patients" view.
- **Occurred**: patient appointment with status `completed`. **DNA**: status `no_show`. `dna_pct = dna ÷ (occurred + dna)`.
- **New patient**: Dentally registration date (`pms_registered_at`) falls in the period.
- **Treatment activity**: treatment items with `completed = true` and `base_chart = false`, dated on `completed_at`, attributed to the practitioner's home site.
- **Billed**: invoice lines by `invoiced_on`, `fee_pence × quantity`. **Settled**: payments with status `settled` by `processed_at`.
- **Leads**: GoHighLevel opportunities by `created_at`; **won** = now at `treatment_started` or `treatment_completed`; **lost** = `not_proceeding` or `failed_to_attend`.
- **Ad spend**: Google + Meta daily spend attributed to a practice through the ad-account → practice mapping.
- **Accounting revenue / costs** (monthly): Xero/QuickBooks accrual rows; a manual row counts only where no synced row exists for that month and bucket. Costs = associates + staff + lab + materials + overhead + other (tax excluded).
